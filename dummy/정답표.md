# 레이더 2차 규칙 — 장면별 정답 표 (D 작성, 3판)

> 근거: `설계-레이더2차.md`(42ccd68) 문장만. B 코드는 보지 않음.
> 상태: **3판 확정 (10/3 사용자 확인).** 검토 3건 + B 설계 해석 반영. 데이터는 이 표가 확정된 뒤 만든다.

## 공통

- 침대(임시, 퀸): x -800~800, y 300~2300, 가르는 선 x=0 (x<0 = L, x=0 은 R), 가장자리 띠 300mm.
  - 띠 = 침대 네 변 안쪽 300mm: x -800~-500 / 500~800, y 300~600 / 2000~2300. **가르는 선 쪽에는 띠 없음.**
  - L 가운데 = x -500~0, y 600~2000 (R 은 좌우 반대).
- 설정값은 설계서 기본값: LEAVE 10초 · MOVE_GAP 1초 · MOVE_MIN 2초 · FOLLOW 30초 · HOLD_MAX 12시간. 장면이 바꾸면 그 장면 머리에 적는다(14번).
- 시각 = 장면 시작부터 초. 프레임 0.089초 간격, 안 보이면 빈 프레임 `[null,null,null]`.
- 「움직임」 점은 직선으로만 움직인다(흔들림 없음) → 이동 거리 = 지나온 길이라 size 구간이 하나로 정해진다.
  - 뒤척임 = 3초 동안 5cm 직선 → size 1 · 걸어 들어오기/나가기 = 30cm 넘게 → size 3
  - 움직임 한 토막은 2.5초 이상(2초 기준과 프레임 오차를 떼어 놓으려고), 끊김은 0.6초 / 1.2초 (1초 기준과 프레임 하나 넘게 떨어지게).
- 모든 점은 레이더 시야(좌우 60도) 안, 보드 구역(x ±1500, y 0~3000) 끝값에서 100mm 넘게 안쪽에 둔다.
- 한 번 사라진 사람이 다시 나타날 때는 **최소 3초 뒤** (보드 트래커는 1.5초 넘게 안 보이거나 700mm 넘게 튀면 새 이름 → 확실히 새 사람으로 보이게).
- 사건 줄 칸: kind · 시작~끝 · side · size · count · (x,y). 허용 오차: 시각 ±0.3초, 자리 ±50mm (off·away 자리 포함, 14번 안전장치 off 자리만 판정 안 함).
- 같은 순간에 나오는 줄의 순서는 판정하지 않는다.

### 준비 동작

- **들어옴 L**: 0~2초 침대 밖 (-1100,1300)→(-850,1300) · 2~5초 침대 안 (-780,1300)→(-400,1300) · 사라짐(누워서 안 보임)
  - 정답: `on` @2 L (-780,1300) · `move` 2~5 L size3 count1 (-780,1300)
- **둘이 잠**: 들어옴 L + 42~45초 R 띠에서 바로 나타나 (780,1300)→(400,1300) · 사라짐
  - R 은 침대 밖에서 보이지 않게 한다(사라진 L 의 기억과 섞일 여지를 없앰).
  - 정답: 들어옴 L 두 줄 + `move` 42~45 R size3 count1 (780,1300) — L 끝(5초)과 37초 차이라 이어짐 아님. occ 이미 1이라 `on` 없음.

## 설계서 해석 (B 답 10/3)

- 정한 것(B 동의): ① 움직임 = 실제로 잡힌 프레임만 ③ 1.5초 넘게 비거나 700mm 넘게 튀면 새 이름 → 「그 칸에서 온 점」 아님 ④ LR size = 칸별 큰 값, count = 칸별 합 ⑤ 안전장치로 꺼져도 10초 대기, 타이머는 침대 안 점이 마지막으로 보인 시각부터 ⑦ 이어짐 앞 건 = 직전 move 한 줄.
- 칸이 꺼졌다 켜지면 occ 0 전이라도 away 냄. 칸 넘김으로 꺼진 건 away 아님.
- **B 해석 → 사용자 확정 (10/3):**
  - ② 띠에서 사라짐: away·나간 시각 = 마지막으로 보인 순간, occ 0 = 그 뒤 약 11.5초(트래커 1.5초 + 10초). → 3번 창 73~75.
  - ⑥ off·away 의 x,y = 「나간 걸 알아챈 자리」: 밖에서 보였으면 처음 밖에서 보인 자리, 띠에서 사라졌으면 마지막 띠 안 자리. 14번 안전장치 off 의 x,y 는 판정 안 함.
